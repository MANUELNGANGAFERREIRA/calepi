# Portefólio — Manuel Calepi Epalanga

Site estático responsivo em HTML, CSS e JavaScript, com estilo editorial escuro, microinterações e animações de entrada.

## Executar

Abra `index.html` no navegador. Para desenvolvimento, recomenda-se usar a extensão Live Server no VS Code.

## Personalização antes de publicar

- A secção `#projectos` inclui o SGE — Sistema de Gestão de Eventos, descrito como projecto académico desenvolvido em grupo. Acrescentar tecnologias utilizadas, imagens e repositório apenas quando esses dados estiverem confirmados.

- Confirmar o nome oficial da instituição de ensino e os dados de contacto.
- Se quiser uma imagem de partilha, adicionar um ficheiro de imagem e configurar `og:image` e `twitter:image` no `<head>`.
